# Assignment 4 — Animated Landing Page

A single-page animated landing page built with HTML, CSS, and vanilla JavaScript.

## Features

- **Fade-in animation** on hero headline and subtitle using `@keyframes`
- **Floating shape** in the hero section with a looping CSS animation
- **Hover transitions** on buttons and feature cards
- **Scroll-triggered reveal** on feature cards using the Intersection Observer API
